Básico Nivel 0 · Electricidad básica

Voltaje, corriente, resistencia

El voltaje V empuja cargas; la corriente I es cuántas cargas pasan por segundo; la resistencia R se opone al paso. Ley de Ohm: V = I · R. Potencia: P = V·I = I²R. Un divisor de tensión con dos resistencias da Vout = Vin · R2/(R1+R2).

Básico Nivel 1 · Del transistor a la lógica

Transistor como interruptor, CMOS

Un MOSFET en corte bloquea (interruptor abierto); en conducción conecta (interruptor cerrado). CMOS usa un NMOS abajo y un PMOS arriba: nunca conducen ambos a la vez, por eso el consumo estático es muy bajo.

Compuertas: AND, OR, NOT y NAND. NAND y NOR son universales: con ellas se construye cualquier lógica.

Niveles lógicos y ruido

Un 0 lógico suele ser < 0.3·VDD y un 1 lógico > 0.7·VDD. El margen de ruido es la diferencia entre lo que una salida garantiza y lo que la entrada siguiente exige.

Intermedio Nivel 2 · Lógica secuencial

Latch, flip-flop D, reloj

Un latch es sensible al nivel; un flip-flop D captura la entrada solo en el flanco del reloj y guarda 1 bit. Una memoria es un array de esos bits.

Setup: D debe estar estable antes del flanco. Hold: D debe seguir estable después. El reset asíncrono (el de sync_fifo.sv) actúa al instante con rst_n; el síncrono solo se evalúa en el flanco.

Intermedio Nivel 3 · La FIFO síncrona

Concepto y punteros

Una FIFO es una cola: el primer dato escrito es el primero leído. Con punteros que se envuelven (wrap-around), wr_ptr == rd_ptr significa tanto vacía como llena. La solución: un bit extra en cada puntero. Si los bits bajos coinciden y el bit alto difiere, está llena; si todo coincide, está vacía.

En este RTL, rd_data es combinacional (mem[rd_ptr]): el dato de la cabeza está disponible sin esperar al flanco.

Código SystemVerilog real del repo

module sync_fifo #(
  parameter int WIDTH = 8,
  parameter int DEPTH = 16          // must be a power of two
) (
  input  logic             clk,
  input  logic             rst_n,
  input  logic             wr_en,
  input  logic [WIDTH-1:0] wr_data,
  output logic             full,
  input  logic             rd_en,
  output logic [WIDTH-1:0] rd_data,
  output logic             empty
);
  localparam int AW = $clog2(DEPTH);
  logic [WIDTH-1:0] mem [DEPTH];
  logic [AW:0]      wr_ptr, rd_ptr;
  assign empty   = (wr_ptr == rd_ptr);
  assign full    = (wr_ptr[AW] != rd_ptr[AW]) && (wr_ptr[AW-1:0] == rd_ptr[AW-1:0]);
  assign rd_data = mem[rd_ptr[AW-1:0]];
  wire do_wr = wr_en && !full;
  wire do_rd = rd_en && !empty;
  always_ff @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      wr_ptr <= '0;
      rd_ptr <= '0;
    end else begin
      if (do_wr) begin
        mem[wr_ptr[AW-1:0]] <= wr_data;
        wr_ptr <= wr_ptr + 1'b1;
      end
      if (do_rd) rd_ptr <= rd_ptr + 1'b1;
    end
  end
endmodule

Experto Nivel 5 · Cobertura y aserciones

Covergroups (idea del testbench)

La cobertura funcional responde: "¿ya probé esto?". Se cubren wr_en, rd_en, full, empty, la ocupación en bins y los cruces entre ellos.

covergroup fifo_cg;
  cp_wr    : coverpoint wr_en;
  cp_rd    : coverpoint rd_en;
  cp_full  : coverpoint full;
  cp_empty : coverpoint empty;
  cp_occ   : coverpoint occupancy {
    bins empty = {0};
    bins low   = {[1 : DEPTH/4]};
    bins mid   = {[DEPTH/4+1 : 3*DEPTH/4]};
    bins high  = {[3*DEPTH/4+1 : DEPTH-1]};
    bins full  = {DEPTH};
  }
  x_occ_ops : cross cp_occ, cp_wr, cp_rd;
endgroup

4 propiedades SVA para este RTL

// 1. full coincide con la definición por punteros
a_full_def: assert property (@(posedge clk) disable iff (!rst_n)
  full == ((wr_ptr[AW] != rd_ptr[AW]) && (wr_ptr[AW-1:0] == rd_ptr[AW-1:0])));

// 2. escribir con la FIFO llena no mueve wr_ptr
a_no_wr_full: assert property (@(posedge clk) disable iff (!rst_n)
  (wr_en && full) |=> $stable(wr_ptr));

// 3. leer con la FIFO vacía no mueve rd_ptr
a_no_rd_empty: assert property (@(posedge clk) disable iff (!rst_n)
  (rd_en && empty) |=> $stable(rd_ptr));

// 4. si no está vacía, rd_data es la cabeza de la memoria
a_head: assert property (@(posedge clk) disable iff (!rst_n)
  !empty |-> rd_data == mem[rd_ptr[AW-1:0]]);

Experto Nivel 6 · Nivel empresa

Regresiones, CI y sign-off

En un flujo profesional se lanzan regresiones con muchas semillas para reproducir y cazar fallas raras; se integran en CI por cada commit; se siguen métricas (cobertura de código y funcional, tasa de bugs) y se cierra con un sign-off checklist: cobertura justificada, aserciones sin fallos, regresión limpia, revisión de diseño y verificador y evidencia archivada. La verificación formal complementa a la simulación probando propiedades de forma exhaustiva.

Cuando lectura y escritura usan relojes distintos (FIFO asíncrona), los punteros cruzan de dominio en código Gray: solo cambia un bit por paso, así un muestreo a mitad de transición nunca da un valor absurdo. Este es un resumen de prácticas generales de la industria.

Experto Nivel 7 · Entrevista: preguntas difíciles y corner cases

Cómo estructurar tu respuesta

  1. Clarifica la spec: pregunta qué se entiende por “full”, “empty”, latencia de lectura, reset y límites de burst.
  2. Plan: define casos dirigidos, aleatorios y métricas de cierre.
  3. Checkers: decide qué va a aserciones SVA y qué al scoreboard.
  4. Cobertura: bins de ocupación, full/empty, cruces wr/rd y alertas ante pasos vacíos.
  5. Corner cases: simultáneos rd+wr en full/empty, wrap-around, DEPTH extremos, reset en tráfico.
  6. Debug: reproduce con misma semilla, busca primer divergencia y no asumas que es el RTL.
